# Myriota UltraLite Software Development Kit

Myriota provides satellite connectivity for massive numbers of long battery life sensors, at ultra-low-cost, from any location on the planet. This repository hosts the Myriota UltraLite Software Development Kit. To get started, take a look at the quick start guide at [support.myriota.com](https://support.myriota.com). For API documentation, check out [docs.myriota.com/ultralite-sdk](https://docs.myriota.com/ultralite-sdk).
